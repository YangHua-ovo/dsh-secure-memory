# Cross-Workspace Memory v0.1.0

发布日期：2026-11-12。

本版聚焦三个基础能力：会话级精确关联、三级记忆检索、原对话页面内的状态更新。继续保留本地加密、独立授权、持续解锁、来源追溯、审计和提示词注入隔离。

## 新增与改进

- **精确选择来源会话**：每个来源工作区可选择全部或指定会话；支持跨工作区多选。空的指定会话列表表示不检索任何会话。新增授权来源不会自动进入当前选择。
- **三级召回**：L1 优先返回关键记忆，L2 提供原文抽取式摘要，L3 保留原始消息片段。结果不足时继续下一层；询问原因、放弃方案、依据或原文时会继续检索 L3。各层都先检查权限与相关性。
- **上下文预算**：默认 1,200，功能栏提供 800 / 1,200 / 1,500 预设；安全说明、来源及正文一起计入。按完整句子装入，不通过截断来源或安全边界满足预算。
- **原页面更新**：设置变化通过局部状态更新反映到功能栏；修复切换会话、保存范围与状态轮询的请求竞态，迟到响应不能覆盖新状态。
- **权限变更立即生效**：撤销、锁定、排除规则或敏感词在检索期间发生变化时，旧结果会被拒绝；清除内存索引与最近来源缓存。

## 下载与安装

- `dsh-secure-memory-0.1.0.tgz`：插件运行文件及文档。解压后，在 DSH 本地插件安装入口中选择 `package` 目录。
- `SHA256SUMS.txt`：上述安装包的 SHA-256 校验值。
- GitHub 自动提供的 Source code 归档：完整源码，含测试和基准脚本。

运行环境：Node.js >= 22.12.0；面向 DSH 0.2.x 插件接口。DSH 接口变动时需重新验证兼容性。

## 数据兼容与升级

安全箱格式和加密参数保持不变。旧版明确选中的工作区兼容为这些工作区的全部范围；新会话仍默认关闭、空选择。派生摘要和索引在内存中构建，不改写源会话。

升级前自行备份安全箱目录中的加密文件（`vault.enc`、`audit.enc`），并妥善保管口令。升级代码的一次性加载后可能需要重新解锁，后续刷新插件状态可在原页面完成。

若回退至 v0.0.2，先关闭有关会话的记忆开关，再使用旧版及保留的加密备份；旧版不能识别新会话细分字段，不能依靠它保留指定来源会话的约束。

## 验证结果

29 项回归测试通过，覆盖原有安全能力、精确范围、三级回退、预算、兼容性、并发权限变化与页面请求竞态。

80 条合成记录、40 个标注问题的基准中，Recall@4、关键记忆 Top1、最终上下文来源命中率和范围正确率均为 100%；结果仅代表这组小型合成样本。未使用真实用户安全箱；未完成本版在真实宿主中的视觉点击验收。

## 已知限制

- 默认 Token 计数采用 UTF-8 字节上界的保守估算，不是模型实际 Token 用量；已提供接入匹配模型 tokenizer 的同步计数接口，尚未接入服务商实际 usage。
- 向量仍为本地词法哈希向量，未引入神经语义 Embedding 模型；摘要为原文摘录，不进行跨来源的模型推断式合成。
- 侧边栏关联目录和设置页面整体重建尚未包含；会话目录当前展示已授权、已索引的可用来源。
- 不支持自动读取 DeepSeek 云聊天历史；云聊天内容仍需用户主动导出后导入。

更多数据模型、权限、计量边界和测试记录见 [v0.1.0 实现说明](../v0.1.0-implementation.md)。
