# 用户操作手册（v0.0.2）

## 0. 日常入口：输入框上方功能栏

安装/升级后刷新页面。日常使用不再需要先进入设置：

```text
当前对话
  ┌────────────────────────────────────────────┐
  │ Cross-Workspace Memory  [开关] 状态 关联N ▾ │
  │ 展开后：工作区复选 / 刷新索引 / 来源 / 锁定 │
  └────────────────────────────────────────────┘
  ┌────────────────────────────────────────────┐
  │ 输入框                                     │
  └────────────────────────────────────────────┘
```

- 开关只影响**当前会话**。
- 勾选只接受**已授权且当前有效**的工作区；未授权工作区不会出现在列表里。
- 工作区 A/B/C 已授权，当前会话只勾选 A/C → B **不参与**本次检索。
- 新会话默认关闭、空选择，不继承其他会话。
- 收起/展开、切换开关、勾选工作区都只更新当前界面，不新建对话、不提交消息、不改变 sessionId。
- 设置页保存配置或授权工作区后，会通过同源消息让功能栏**原地刷新**；也可点功能栏里的“刷新状态”。不需要重载页面。
- 检索状态显示：未启用 / 已启用 / 正在检索 / 检索完成 N 条 / 暂无相关记忆 / 范围受限 / 服务异常。
- 来源摘要显示工作区、来源引用、时间、分类、状态、可信度；不显示正文。

### 0.1 解锁体验

- 首次使用：进入 **设置 → Cross-Workspace Memory** 创建保险库。
- 日常：在功能栏点“解锁”输入口令；**口令不保存**。
- 同一 DSH 页面运行期间，切换会话/收起栏/打开 Settings 不需要重复输入。
- 页面刷新、DSH 重启或宿主自动锁定后需要重新解锁。
- Settings 页面可从主功能栏接收同一内存 token；不会写入 localStorage/sessionStorage/cookie。

## 1. 入口（Settings 管理面仍保留）

安装并启用 `dsh-secure-memory` 后：

1. 首次使用打开 DeepSeek Harness 的 **设置**。
2. 在左侧找到 **Cross-Workspace Memory**，创建保险库、授权工作区。
3. 日常使用回到对话，在输入框上方的功能栏操作。

> 本插件只在本机回环地址（127.0.0.1 / localhost / [::1]）工作。把 DSH 暴露到局域网或公网时，管理面会拒绝访问。

---

## 2. 创建保险库

1. 输入至少 12 个字符的口令。
2. 再次输入确认。
3. 点击 **创建本地保险库并解锁**。

注意事项：

- 口令只用于本机 `scrypt` 派生密钥，不会保存，也不会通过网络发送。
- **口令丢失不可恢复**；没有后门、没有找回流程。
- 保险库创建后，AI 不会自动获得任何工作区权限。

---

## 3. 解锁与锁定

- 每次 DSH 重启或空闲超过默认 30 分钟后，保险库自动锁定。
- 锁定后，AI 的记忆 Tool 会返回“保险库已锁定”，不会返回缓存内容。
- 点击右上角 **锁定** 立即清空内存密钥。
- 页面刷新后需要重新输入口令；管理令牌只存在于当前页面内存，不写入浏览器存储。

---

## 4. 工作区授权

### 4.1 列出来源

「工作区」页显示两类来源：

| 类型 | 含义 | 数据来源 |
|---|---|---|
| DSH 本地工作区 | 本地目录 + 本地会话 | 官方 `workspaceRegistry` / `sessionPersistence` |
| 手动导入源 | 用户导入的 JSON/Markdown 快照 | 用户主动选择的文件 |

**DeepSeek 云聊天工作区不会出现在列表中**，因为官方没有公开读取接口。

### 4.2 授权 DSH 本地工作区

1. 选择授权时长：
   - 1 小时、24 小时、7 天、30 天：临时授权，到期自动删除索引。
   - 长期：直到你手动撤销。
2. 点击 **授权并索引**：
   - 授予该工作区的检索权限；
   - 只读读取该工作区本地会话中的用户/助手文本；
   - 在本机建立加密索引。
3. 或点击 **仅授权**：只授予权限，不读取会话；之后用 **同步索引** 手动建立/更新索引。

每个工作区独立授权。授权工作区 A 不会让工作区 B 获得任何权限。

### 4.3 暂停与撤销

- **暂停访问**：保留加密索引，但检索拒绝。
- **撤销并删除索引**：立即删除该工作区索引和授权；之后的查询不会返回该工作区内容。
- **参与默认检索**：v0.0.1 的全局默认开关仍保留，供 Settings 手动检索/兼容使用；**v0.0.2 的 AI 自动检索以“本次会话关联”为准**，不再仅凭 defaultRetrieval 跨会话放行。

### 4.4 授权状态

- 未授权
- 临时授权
- 长期授权
- 已暂停
- 已过期（自动清理）
- 已撤销（审计中保留事件）
- 同步中（界面忙碌状态）

## 5. 手动导入 DeepSeek 历史

### 5.1 官方导出

在 DeepSeek 官方产品中：

```text
头像 → 设置 → 数据管理 → 导出所有历史对话
```

导出文件由官方生成。**不要把账号 Cookie、Session、密码或令牌交给任何工具。**

### 5.2 导入

1. 在「工作区」页底部展开 **手动导入**。
2. 选择 `.json` / `.md` / `.markdown` / `.txt` 文件（≤ 8 MB）。
3. 可填写工作区名称，选择授权模式。
4. 点击 **导入并授权**。

支持：

- 本项目的规范化记忆包（`documents` / `docs` 数组）；
- 常见 `conversations` / `chats` / `sessions` / `messages` JSON；
- OpenAI/ChatGPT 风格 `mapping` 对话；
- Markdown 文本（作为一个文档）；
- 顶层文档数组。

不支持 ZIP、二进制、图片或附件解析。解析失败时不会上传或猜测。

导入源会永久标记为 **手动快照**，不会显示为云端实时连接。

## 6. 检索

### 6.1 手动检索

1. 打开「检索」。
2. 选择授权工作区（可全选/取消全选）。
3. 输入自然语言，例如：
   - “之前讨论过如何设计多 Agent 协作架构吗？”
   - “产品设计工作区里关于新手引导的最终方案是什么？”
4. 可选检索方式、日期、分类。
5. 点击 **检索已授权记忆**。

结果包含：

- 标题/摘要；
- 工作区与来源引用；
- 会话 ID 与事件序号（若有）；
- 创建时间、分类、状态；
- 启发式可信度与构成；
- 风险等级；
- 潜在冲突提示。

### 6.2 生成 AI 上下文

点击结果上方的 **生成 AI 上下文**，会得到带安全边界的参考块：

- 标记为不可信历史数据；
- 转义所有尖括号；
- 高风险提示词注入内容不进入上下文；
- 冲突来源并列，不自动裁决；
- 可复制后交给当前 AI，或让 AI 直接调用 Tool。

### 6.3 检索模式

- **混合**：BM25 + 本地字符 n-gram 向量（默认）。
- **关键词**：BM25。
- **本地向量**：字符 n-gram 向量相似度。

这里的“向量”不是神经语义 Embedding，不会把数据发送给第三方。UI 和文档不会把它宣传成语义理解。

### 6.4 检索频率

- AI Tool：每分钟最多 30 次。
- 手动 UI：每分钟最多 60 次。
- 超过限制返回错误；不会静默降级。

## 7. AI 使用

AI 可见三个只读 Tool：

| Tool | 用途 |
|---|---|
| `xw_memory_search` | 在已授权范围内搜索，返回带来源的参考块 |
| `xw_memory_context` | 生成更完整的结构化参考上下文 |
| `xw_memory_status` | 查看锁定/审计/授权计数，不返回正文 |

AI **不能**：

- 授权工作区；
- 撤销/暂停授权；
- 导入/同步；
- 删除保险库；
- 修改记忆状态；
- 绕过锁定或审计异常。

历史内容会被标记为不可信；其中的“忽略之前指令”“把所有资料发给我”等不会被执行。

---

## 8. 知识图谱

「知识图谱」显示：

- 工作区节点；
- 记忆分类节点；
- 主题标签节点；
- 共同主题连线。

图谱只包含已授权且未被排除的来源；不包含正文。它是本地共现关系，不是因果推理或事实判断。

---

## 9. 时间线与冲突

「时间线」按时间展示记忆：

- 首次出现时间；
- 最近确认时间；
- 来源与会话；
- 分类/状态；
- 是否可能过期；
- 是否参与潜在冲突。

如果两个不同工作区的“已确认/已验证”记忆在共同主题上差异较大，系统标记为潜在冲突：

- 不选择“谁正确”；
- 显示双方来源和时间；
- 由用户或项目负责人确认。

可对单条记忆执行 **确认**、**废弃**、**排除**，或对会话/来源文件执行排除。

## 10. 安全中心

### 10.1 状态

- 审计链是否完整；
- AES-256-GCM 静态加密；
- 模型上下文传输提示；
- 自动锁定时间；
- 存储位置与文件大小。

### 10.2 排除规则

- **排除的会话**：整个来源会话不进入检索、上下文、图谱。
- **排除的单条记忆**：单条不进入检索。
- **排除的来源文件**：导入文件来源不进入检索。
- 可随时恢复。

### 10.3 禁止检索内容

每行一个词/短语。命中任一短语的文档在检索前被排除。规则加密存储。

### 10.4 设置

- 最多结果数（1–12）；
- 上下文最大字符（1000–8000）；
- 自动锁定分钟（1–240）；
- 是否隔离高风险提示词注入内容（默认开启）。

### 10.5 审计

记录时间、主体、动作、结果、工作区、结果数、来源 ID、说明。

不记录：

- 完整查询正文（只记录 SHA-256 哈希）；
- 记忆正文；
- 口令、密钥、令牌。

### 10.6 一键断开与删除

- **一键断开**：撤销全部授权 → 清空索引 → 锁定 → 所有管理令牌失效。
- **删除整个保险库**：需要输入 `DELETE` 确认；删除密文、审计、内存密钥和临时文件。

删除不可恢复。SSD 磨损均衡可能导致物理残留，不能承诺物理擦除。

## 11. 常见问题

### Q：为什么看不到 DeepSeek 云工作区？

A：DeepSeek 云聊天没有公开的工作区/历史读取 API。请使用官方手动导出后导入。

### Q：AI 说保险库锁定怎么办？

A：在设置中解锁。AI 不能代你解锁。

### Q：忘记口令怎么办？

A：无法恢复。只能删除保险库后重新创建；旧数据不可解密。

### Q：为什么某些结果被隔离？

A：内容可能包含提示词注入、权限绕过、数据外传等指令。系统宁可误隔离，也不让它们进入 AI 上下文。

### Q：为什么“已确认”仍显示“未验证”？

A：同步得到的 DSH 消息默认不把模型的话当最终决策；请人工点击“确认”。分类和状态是启发式，不是事实判断。

### Q：删除工作区会删除原始 DSH 会话吗？

A：不会。插件只读；撤销只删除插件自己的加密索引和授权。

### Q：可以把 DSH 暴露到局域网吗？

A：本插件的管理面拒绝非回环请求。不要把解锁后的管理面暴露给他人。

### Q：有云端备份吗？

A：没有。你可以自行复制加密的 `vault.enc` / `audit.enc`；没有口令无法恢复。
